OpenEVV

Bundled test release: The downloadable add-on includes the x64 engine and IBM-derived language data. Redistribution rights for those data remain unresolved; permission to publicly redistribute them has not been established. Publication does not resolve that uncertainty or grant rights to the data. See NOTICE.md and ENGINE-NOTICE.txt in the package for licensing scope and engine provenance. Custom builds may use a different engine and offer different languages.

11 kHz (Classic) is the recommended default. 22 kHz is experimental. Resampled rates do not add speech information.

Languages

The locally tested multilingual engine includes American and British English, German, Spanish from Spain and Latin America, French from France and Canada, Italian, Japanese and Polish. Language and voice remain separate Speech settings. Automatic language changes preserve the selected voice and restore the default language afterwards.

Japanese and Polish are marked Experimental. Japanese has known failures in individual engine test cases. Polish is incomplete and still uses some Italian rules. Additional dictionaries apply only where matching language files exist; other languages keep their original pronunciation.

Some raw Eloquence text annotations crash the Japanese engine. The driver therefore removes backquotes from Japanese text even when voice tags are enabled, including automatic language changes. NVDA's own speech commands are processed separately. This restriction does not fix the underlying engine defect.

NVDA symbol pronunciation

Known symbols are processed by NVDA using its own language, symbol level, enabled CLDR dictionaries and personal symbol entries. OpenEVV does not process their names a second time. This add-on adds German and English labels for all 128 Unicode box-drawing symbols. Other locales use English fallback for these added labels. No personal configuration is rewritten.

At None, Some and Most, the added box-drawing symbols are silent. At All, NVDA announces their names. Character navigation identifies individual symbols even at general level None. Arrows, mathematical symbols, emoji and punctuation retain NVDA's existing definitions and levels. User entries in Punctuation/Symbol Pronunciation take precedence. The supplementary definitions apply to all synthesizers while this add-on is enabled. Restart NVDA after installation. Symbols outside these tables can still require a personal symbol entry; this is not universal Unicode support.

Spaced punctuation

NVDA can retain raw punctuation for pauses even when symbol verbosity is set to None. Western Eloquence voices may pronounce those marks when spaces separate them from words. For ordinary speech, the driver changes ( text ) to (text) and Text : next to Text: next, retaining the marks for prosody. Explicit spelling and symbol names already supplied by NVDA are preserved. The correction does not change NVDA settings, cross speech-command boundaries, or apply to raw voice-tag mode or completely isolated symbols without adjacent text.

Names and unsupported accents

Western voices use Windows-1252. Unsupported Latin letters with canonical accent decompositions are approximated using letters the engine can encode: for example, Petr Čech becomes Petr Cech. Supported letters such as umlauts, accented vowels, Š and Ž remain intact. This avoids a replacement question mark but does not guarantee Czech or other foreign-language pronunciation. Non-decomposable letters and other unsupported scripts may still need NVDA symbol processing or a pronunciation dictionary.

Optional pronunciation dictionaries

Select the pronunciation profile in Speech settings. Original uses no additional dictionaries. In the OpenEVV settings category, download Alternative (English/Spanish) or Community (German/English), open your custom directory, or reload the active dictionary. Downloads do not select a different profile automatically. Missing dictionaries for a language leave that language's original pronunciation intact.

Sources: AltIBMTTSDictionaries and IBMTTSDictionaries. These optional data files are downloaded separately and are not bundled. Own files and downloaded profiles are stored separately in the NVDA configuration directory under openevvDictionaries and survive add-on updates.

Custom filenames: ENUmain.dic, ENUroot.dic, ENUabbr.dic for American English; DEUmain.dic, DEUroot.dic, DEUabbr.dic for German. Each line contains a word, a tab and its replacement. Use Windows-1252 or UTF-8 with BOM. Main is for whole words, root for stems, abbr for abbreviations; enable abbreviation expansion to use abbreviation entries. Empty lines and lines starting with # or ; are ignored. Reload after editing. Invalid files retain the previously loaded profile and show an error in the OpenEVV status field.

The large English Community dictionary takes longer to load on an automatic language change than Original or Alternative. Try Original or Alternative if that affects navigation responsiveness.

Pronunciation tools

NVDA Settings → OpenEVV now provides four keyboard-accessible, scrollable tool dialogs. These optional tools retain the eight standard voices and Classic default.

Dictionary editor

Select a Western language and dictionary volume, search or edit an entry, then apply it to the list and save the file. Deletions also take effect on saving. Preview reads the typed replacement without saving. Original phoneme analysis uses the engine's original dictionary. Expert entries use ECI phonemes, not IPA, without the outer brackets or backquotes. Japanese and Polish are excluded from this editor and phoneme analysis.

The Speech dictionary choices include Alternative + custom corrections and Community + custom corrections. A custom entry overrides an identical byte key in the same volume. Other downloaded entries remain intact, and updates preserve custom files. Original activates neither downloaded nor custom dictionaries. Saving preserves comment lines at the top of the file and retains CP1252 or UTF-8-BOM encoding. Conflicting external edits are rejected; reopen the editor to load them.

Named voice presets

Save, apply or delete named combinations of language, voice, speed, voice controls, dictionary profile and sample rate. The eight voice IDs stay unchanged. Saving/deleting a preset is immediate. Applying changes current settings but does not implicitly save NVDA configuration; use NVDA+Control+C to persist them. Continue using NVDA configuration profiles for application or Say All triggers.

Words per minute

Enter 149–1297 WPM. Applying chooses the nearest available percentage/rate-boost combination and displays the achieved engine value. Existing rate shortcuts remain effective. The number is the engine setting, not a guarantee of measured words per minute for every text.

Explicit pronunciation preview

Preview entered text as an ordinal, telephone number, currency amount, explicitly ordered date or ECI phoneme sequence. This applies only to the preview, not to ordinary NVDA speech. Special formats are supported for the eight Western language variants. Canadian French dates are normalized to the working year/month/day command to avoid its defective native day/month/year path. The selected default language and voice are restored afterwards.

Named settings are stored in openevvDictionaries/voice-presets.json. Custom files and presets follow NVDA's secure-screen configuration copy. Management tools are disabled on secure screens; prepared dictionary combinations are only read.

Windows sign-in

  1. Use an installed copy of NVDA, select OpenEVV and save configuration with NVDA+Control+C.
  2. Open General settings (the OpenEVV panel has a shortcut).
  3. Enable NVDA during sign-in.
  4. Use currently saved settings during sign-in and on secure screens, include OpenEVV in the add-on selection and confirm Windows elevation.

Repeat the copy after add-on or dictionary updates. NVDA copies the DLL and dictionary data; no helper EXE is needed. Secure mode reads prepared dictionaries and provides no downloader or file management. Installing the add-on alone does not enable system-wide startup. Portable NVDA cannot configure the Windows sign-in service.
